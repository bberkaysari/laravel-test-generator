# Laravel Test Generator

Universal Laravel test generator without AI.

## Status

🚧 **Under Development** - MVP Phase

## Installation
```bash
composer require --dev yourname/laravel-test-generator
```

## Usage
```bash
php artisan test:generate
```

## Development
```bash
# Install dependencies
composer install

# Run tests
composer test

# Static analysis
composer analyse

# Code formatting
composer format
```
